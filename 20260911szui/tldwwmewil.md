# 氨基酸奶粉是什么做的，母乳和氨基酸奶粉混合喂养依然有过敏反应

当妈的自然都想纯母乳喂养，但是宝宝出生前几个月，母乳不足时，为了保证宝宝的健康成长，这时就需要奶粉的补充。等宝宝成长到一定阶段后，母乳不能完全满足宝宝的需求，也需要母乳以外的营养来补充。而婴幼儿配方羊奶粉则是很多妈妈的首选。选择奶粉和母乳的混合喂养，喂养的方式有代授法和补授法。那么氨基酸奶粉是什么做的，母乳和氨基酸奶粉混合喂养依然有过敏反应
氨基酸奶粉是什么做的
　　氨基酸奶粉也称为“无敏配方”，无敏是指所含的成分不会引起任何过敏的可能，主要适用于牛奶过敏或多种食物蛋白过敏的饮食治疗。氨基酸是蛋白质的基本单位，人体摄入后的食物蛋白，在体内首先需要分解为氨基酸，然后才能被机体吸收和利用。

　　氨基酸奶粉不同于水解奶粉，水解奶粉也称“低敏奶粉”，是通过特殊工艺把牛奶中的蛋白质降解处理后成为肽链，以降低蛋白的过敏原性。致敏程度的高度取决于肽链的长短，降解程度越深，致敏性就越低。所以根据工艺的复杂程度和肽链的长短，市场上的水解奶粉，又分为部分水解奶粉和深度水解奶粉。部分水解奶粉，只能用于食物过敏的饮食预防;而深度水解奶粉，可用于部分轻到中度牛奶过敏的饮食治疗。对于中度或重度牛奶过敏的宝宝，须食用氨基 酸奶粉。相比水解奶粉，氨基酸奶粉不含任何过敏物质，疗效更好。 各种配方奶粉的致敏性由高到低的排位： 普通婴儿奶粉 → 部分水解奶粉 → 深度水解奶粉 → 氨基酸奶粉 婴儿氨基酸奶粉是将要部署的普通奶的基础上除去酪蛋白，乳清蛋白的增加的一部分;除去大部分的饱和脂肪酸，加到植物油，由此增加了不饱和脂肪酸，降低矿物质含量，以减少对肾脏的婴儿的负担;还添加了微量元素，维生素，氨基酸，或一些其它成分，使之更接近人乳。除了上述特点，婴幼儿配方奶粉生产企业的质量，而且还根据不同年龄段的宝宝的特点，适当补充有益宝宝健康，聪明的营养素。如DHA，核苷酸，寡糖。 其实婴儿多吃氨基酸奶粉的话，对于健康和生长发育都是有一定的帮助的，尤其使氨基酸奶粉中含有丰富的蛋白质和脂肪，对于宝宝的生长是有益处的。 对宝宝来说，母乳是最好的成长食粮。但当妈妈或宝宝本身出现特殊的健康问题，特殊配方的奶粉，可能就要成为宝宝的主要食物来源了。过敏宝宝、身患特殊疾病的宝宝急需特殊配方奶粉喂养，但却普遍面临购买困难。目前，市场上的奶粉，都属于以科技方法制造的“配方奶粉”，即以牛奶为原料，另外再加入或抽取出某些物质调配而成。但宝宝出现什么样的特殊表现，才需要选用特殊医学用途婴儿配方奶粉(以下简称“特殊配方粉”)， 业内人士指出，由于我国企业研发的特殊配方粉品种和数量并不多，进口品牌的特殊配方奶粉进入中国的品种也不是很齐全，导致有些患特殊疾病的宝宝，如苯丙酮尿症、枫糖尿症、甲基丙二酸血症等，其对应的特殊配方奶粉购买困难，不少宝爸宝妈只能求助于“万能的网络”。
母乳和氨基酸奶粉混合喂养依然有过敏反应
　　补授法就是每一次喂养都是先喂母乳，母乳不够时，再补充奶粉。6月龄内婴儿母乳不足时，仍应维持必要的吸吮次数，以刺激母乳分泌，补授的乳量根据婴儿食欲及母乳分泌量而定，即“缺多少补多少”。

　　代授法：

　　母乳和奶粉完全分开，一次完全母乳，一次完全奶粉，交替进行。一般用于6月龄以后无法坚持母乳喂养的情况，可逐渐减少母乳喂养的次数，用配方奶替代母乳。

　　妈妈应该根据自身情况自行选择使用哪一种方法。但是补授法可能会不利于宝宝消化，容易形成乳头错觉，从而引发宝宝对奶瓶以及奶粉的厌恶和拒绝。所以一般来说，建议采取代授法。

　　一、如何控制混合喂养的量

　　在宝宝出生后的1～2月，应该每天喂7次，每一次隔三个小时。第三个月起，改为每天5次，每次间隔四个小时。同时要根据宝宝的月龄，增加不同的辅助食品，以满足婴儿成长的需要。

　　而奶粉添加的量需要根据宝宝白天睡觉的时间来确定，如果宝宝白天睡得过多，则应该减少或者停止奶粉的增加。

　　二、选择合适的奶嘴也很重要

　　虽然再好的奶嘴和吃妈妈奶的感觉还是不一样，但是奶嘴的选择和使用得当对于宝宝接受奶瓶也很关键。

　　最好选择柔软度适中，接近妈妈乳头的奶嘴，而且可以让宝宝多试几个奶嘴挑选出最喜欢的那一个。同时奶嘴孔的大小以适中为佳，判断标准是将奶瓶倒置，约1滴每秒、连续滴出的流速是比较适合的。

　　喝奶前把奶嘴用温水冲一下，使其变软些，和妈妈乳头的温度相近。另外，喂养前也可以在奶嘴上涂抹一些母乳，便于宝宝很快进入角色。

　　三、混合喂养的注意事项

　　1、奶具要保持清洁干爽。每一次使用奶瓶奶嘴后要清洗干净并晾干。

　　2、奶的温度要适中。冷藏过的奶应该采用在流动的热水中加热的方法。最好不要直接在微波炉里面加热，以避免加热温度过高而破坏奶的养分。

　　3、夜间可以全部母乳喂养。因为夜间乳汁分泌量较多，而宝宝需求量相对较少，一般能够满足宝宝的需要。不起床冲奶也可以保证妈妈的睡眠质量。但是如果宝宝实在是吃不饱，那只好以奶粉为主。

　　4、每一次冲奶粉的时候的量最好就是宝宝一次能吃的量。最好不让宝宝吃放置时间过长的奶粉。

　　5、妈妈一般不要给宝宝更换奶粉的种类，否则有可能造成宝宝产生厌食的情况。如果必须要更换奶粉种类的时候，应该采取循序渐进的方式，保证宝宝摄入的营养充足。

　　蓝河绵羊奶被誉为最接近母乳的奶粉，氨基酸水平和母乳类似，容易被宝宝接受、易消化吸收，同时优质的奶源能够从源头上保证奶粉的品质，解决妈妈的担忧，不仅如此，蓝河绵羊奶充足的营养、科学的配方能够很好的满足宝宝生长所需。

　　6、混合喂养是母乳不足时的补助手段，如果母乳足够，妈妈也没有特殊情况，蓝河建议完全母乳喂养是更好的选择。

　　7、混合喂养时还是应该以母乳为主。
