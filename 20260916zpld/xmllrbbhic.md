# 健康指南：孕期超声全攻略，看这一篇就够啦！

> 更新时间：2026-09-16 (UTC+8)

生一个健康的宝宝是每一个家庭共同的心愿。优生优育，提高人口质量已经被自然提高到一个重要位置。胎儿宫内监测已经成为围产期保健的重要组成部分。超声检查兼有无创、安全、便捷、价廉、实时和动态等优点，因此成为胎儿生长发育过程中最常用的影像学检查。

产前超声检查包括早孕期超声检查、胎儿NT超声检查、中晚孕期超声检查，产科医生需要根据孕周、孕产史、上次胎儿超声检查情况等开具不同的超声检查申请单，下面和我一起了解孕期超声检查的分类和检查内容吧！

**Let’s Go!****孕期超声检查时机**
1.首先在月经推迟后，最早可以在停经5-6周的时候，通过阴道超声初步判断有没有怀孕，排除宫外孕可能，但是要知道胚胎发育是否正常，以及其它确切信息，大部分要等到8周。8周后可见观察孕囊(数量、大小、形状)；胎芽(数目、头臀长或双顶径、胎心搏动)；子宫(形态)；双附件(大小、是否 存在赘生物)等内容。对于多胎妊娠，还强调再进行绒毛膜性检查。

2.在妊娠11—13+6周：观察胎儿头臀长、核对孕周；鼻骨的显示和颈后透明层厚度(NT)的测量；NT值随孕周的增大而增厚，≥3.0mm为异常增厚,增厚的原因：多见于染色体异常，如21-三体、13-三体、18-三体综合征，有报道异常增厚可检出86%的染色体三体病例。NT增厚也可见胎儿非染色体异常，如先天性心脏结构异常、骨骼发育异常、感染、代谢异常、双胎输血综合征等；双胎绒毛膜的判断；妇科并发症的判断。

3.妊娠20—24周会进行胎儿系统超声筛查，除常规超声检查内容外，还观察胎儿头部（大脑、侧脑室、丘脑）、颜面、心脏（四腔心）脊柱和腹部（肝、胃、双肾、膀胱）,筛查胎儿的九大致死性严重畸形：包括无脑畸形、无叶型前脑无裂畸形（简称无叶全前脑）、严重脑膜脑膨出、严重开放性脊柱裂伴脊髓脊膜膨出、单心室、单一大动脉、双肾缺如、严重胸腹壁缺损并内脏外翻、四肢严重短小的致死性骨发育不良。

4.妊娠28—32周进行的超声检查是来进一步进行晚发畸形的补漏检查，并判断胎儿生长发育情况、羊水量、胎位、胎盘位置等；

5.妊娠37—41周的超声检查，评估胎儿大小、羊水量、胎盘成熟度、胎位等。

**超声检查胎儿是需要注意些什么呢？**
1.超声的安全性是不需要担心的，准确地说目前尚未发现超声对胎儿能造成确切的伤害；

2.孕期超声检查前可饮食；

3.孕妇肥胖所造成的检查效果不满意目前技术上是没办法克服的；羊水量适中对顺利完成检查是很有利的；

4. 2个月内的早孕超声检查可能需要憋适量的小便，其余时间是不需要憋小便的；

5.如没有禁忌症，整个孕期都是可以行经阴道超声检查的，早孕期则建议经阴道检查，中晚孕则是有需要才经阴道检查，比如宫颈管的检查，前置胎盘及前置血管的检查经阴道超声明确诊断；

6.孕期超声检查请务必带上好心情，孕妇好心情，胎儿也会配合得好一点。11~13+6周的超声检查(尤其需要胎儿体位配合的一次检查)，事先特意叮嘱带上好心情；研究表明，自第三个月起，胎儿对外界环境是有反应的；

7.孕11~13+6周，20~24周超声检查是孕期最重要的两次超声检查，有条件的务必不要错过。前一个时间段范围更严格，属于过了这个村就没这个店的那种，后一个时间段范围可适当放宽，21~23周是个相对比较合适的孕周，肥胖者可适当后延；

8.通过了前两次最重要的超声检查后，在28~32周可进行最后一次的“查漏补缺”；当然，如果有情况是可以适当增加检查次数的；

9.胎儿前六个月的体重只占出生体重的1/3，后三个月的体重增长占了2/3；所以中孕期是不必关注胎儿体重的；

10.晚孕期的超声测量是不够准确的，因为无法获得满意的标准图像，所以晚孕期的体重也是不够准确的，仅供参考。

各位孕妈们一定要按时产检，超声是必不可少的哦。但超声不是万能的，并不是所有的畸形都能筛查出来，但没有超声是万万不能的。祝所有孕妈们能够获得健康的宝宝。
